# Parish Hub ⛪

A small, free web app for a local church community. No server, no database, no sign-ups — just open it on a phone or computer.

## What it does

- **Next Mass countdown**: always shows the next service and how long until it starts
- **Weekly Mass times**: today highlighted
- **What's on**: upcoming events with category filters and a one-tap **+ Calendar** button (.ics for iPhone, Android, Outlook, Google)
- **Prayer wall**: share an intention, tap *“I prayed”* on others (saved on the device only, nothing leaves the phone)
- **Serve with us**: pick volunteer roles and an email to the parish office is written for you
- **Visit & contact**: address, office hours, tap-to-call, directions
- Works **offline** and can be **installed on a phone's home screen**

## Make it your parish's

Edit **`data.js`** — parish name, address, Mass times, events, announcements and volunteer roles. Nothing else needs touching.

## Run it

Open `index.html` in a browser, or host it free with **GitHub Pages**:
Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save.

## Tech

Plain HTML, CSS and JavaScript. No build step, no dependencies. MIT licensed: free for any church or community group to use.
